# Pirate Defense (해적선 방어 게임)

C++와 SFML 3.1.0으로 만든 해적선 배경 2D 방어 게임 팀 프로젝트입니다.

- 기간: 2026.09.14 ~ 2026.09.17
- 인원: 5명 (팀장 1, 부팀장 1, 팀원 3) — 팀 프로젝트
- 기술: C++, SFML 3.1.0, Visual Studio 2022

## 주요 기능

- 싱글 플레이 / TCP 기반 LAN 멀티플레이
- 일반 적·승선 적·보스 등장, 상태 기반 스프라이트 애니메이션
- 포탄 종류, 골드, 상점, 업그레이드 시스템
- 엔딩 컷신

## 구성

| 위치 | 내용 |
|---|---|
| `main.cpp` | 창 생성, 게임 루프 |
| `SingleGame.*`, `MultiGame.*` | 싱글·멀티 게임 진행 |
| `NetworkManager.*` | 멀티플레이 네트워크 통신 |
| `Render.hpp`, `SpriteAnimation.hpp` | 화면 렌더링, 스프라이트 애니메이션 |
| `Items/` | 포탄·골드·상점·업그레이드 |
| `assets/images/pixel/` | 플레이어·적·보스·이펙트·UI 이미지 |

## 담당 파트 (유동호)

> 통합 과정에서 팀원 코드와 합쳐져, 아래 경로는 해당 기능이 최종적으로 들어 있는 위치입니다.

- **게임 루프 및 화면 렌더링**: 데스크톱 해상도 기반 윈도우드 풀스크린 출력과 게임 루프 (`main.cpp`)
- **플레이어 이동 및 방어 로직**: 이동 조작과 방어·전투 프로토타입

## 실행

- 바로 실행: `run.cmd` 실행 (`Runtime/`과 `assets/`를 함께 둬야 합니다)
- 빌드: Visual Studio 2022, SFML 3.1.0을 `C:\SFML\SFML-3.1.0`에 설치 후 Release / x64로 빌드
- SFML 라이선스: `SFML-license.md`
